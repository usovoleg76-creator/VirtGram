VirtGram Firebase — инструкция

1. В Firebase Authentication включи Email/Password.
2. В Firestore Database → Rules вставь firestore.rules и нажми Publish.
3. Размести index.html на HTTPS-хостинге (например Firebase Hosting). Локальное открытие HTML через файловый менеджер часто блокирует Firebase-модули.
4. Открой сайт и создай аккаунт. Для проверки создай второй аккаунт на другом устройстве/браузере.
5. Нажми + и введи точный email второго зарегистрированного пользователя.
6. Сообщения синхронизируются через Firestore.

Это веб-версия, не APK. Для APK потребуется Android-оболочка/сборка. Не используй тестовые правила Firestore в опубликованном приложении.
